## 用户确认的规则

1. 每大境界分初期、中期、后期、圆满，起点为炼气初期。
2. 普通敌人、精英和 Boss 提供丹田灵气，小境界满灵气自动突破，不去祭坛、不消耗材料。
3. 大境界材料由对应地图最终 Boss 掉落，祭坛手动突破。
4. 每次突破消耗阶段灵气并保留溢出，大境界另消耗一份材料。
5. 死亡保留已完成境界、已记录且未消耗资源、已解锁武器和已登记蓝图；未记录新增资源丢失。
6. 商人复用奇遇房，保留首版八模板规模。

## 明示的技术决定

- 不维护第二套经验／永久修为条，成长计数统一为丹田灵气；战斗真气仍独立。
- 灵气优先消耗未记录部分，再扣已记录余额；防止死亡返还已消耗资源。
- 自动突破同步提交关联继续快照，恢复到该房间安全点；未记录资源仍未永久登记。这是保存一致性的实现选择，不是用户新增的祭坛功能。
- 永久档案与局内状态逻辑分离、同封套原子持久化，避免半笔成长事务。
- 首图 Boss 按炼气境可击败设计，胜利后返回原祭坛筑基；可在新探索重新获取丢失的关键材料。
- 当前采用二维制作路线建议，不安装三维软件或骨骼插件。现有主角图不重画。
