## 可玩内容

- 八种手工模板、十个探索节点。入口两战斗分支汇入旧碑；奖励／商店分别位于两处可选支路，种子决定前后；弩室 → 精英 → 同一祭坛 → Boss。入口战斗房间另有随机单向连边，共3种有向拓扑、6种布局。所有节点从入口可达且可向Boss前进，精英与祭坛不可绕过。
- 种子记录于运行日志与行囊；地图、掉落、强化使用独立RNG。同种子与操作顺序重现结果；正常新局重新生成种子。本轮没有继续探索的磁盘恢复。
- 保留四普通敌人、精英与Boss原行为；敌人死亡事件实际增加丹田灵气、灵石、材料和装备记录。奖励自动收取，HUD显示到账及材料／装备名，行囊可查余额和实例。Boss发一份筑基灵髓；精英不发该材料。
- 战斗房首次清场三选一，含精英和Boss。按权重抽不重复候选，关闭重开保持原候选，选择一次；六类加成实际接入角色。生命、防御、攻击、暴击、闪避冷却和攻击时长相对基准计算，不重复叠乘。局内显示真实属性修正。
- 奖励房宝箱只开一次，真实生成装备实例。装备有唯一实例ID和equipment_dropped信号；当前仅是掉落接口与本局行囊，不能穿戴、解锁或提供装备属性。
- 旧碑“残剑问心”可选当前生命15%代价换攻击20%，或获取灵气；选择结果真实执行，完成后不再提供选择，不会换选项重复发奖。
- 无面商人展示真实库存和价格；治疗、砺剑石和替劫符均有实际作用。余额、满血、库存、加成上限检查失败不扣款。替劫符在真实致死伤害时只保留一次1生命并消费。
- 路线／强化／奇遇／商店／行囊期间冻结世界；Esc关闭当前界面并恢复操作，不误开暂停菜单。普通暂停、设置、返回菜单和退出仍有效。
- 祭坛本轮只恢复生命，明确说明尚不能记录资源或突破。Boss清场后可返回原祭坛，回访不刷怪、不重发材料或强化。
- 死亡同步清除本局余额、材料、装备、强化、事件与商品状态，并恢复基础属性；倒下动作后显示实际丢失摘要。重新探索创建新状态和种子。退出菜单再开新局同样不带上局内容，继续游戏仍禁用。
