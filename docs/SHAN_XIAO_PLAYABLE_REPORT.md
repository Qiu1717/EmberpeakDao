# 山魈幼体单房美术接入报告

日期2026-10-23。用户已批准“一只山魈在一个房间里”的实际战斗样板；本轮不进入阶段4，不扩展全角色动画。

## 当前结果

新增主菜单“山魈美术样板”入口，独立房间中使用真实Player、Enemy、平台碰撞、物理攻击与生命值；山魈的身体绘制由透明手绘动作替换。可移动、跳跃、攻击、闪避、暂停／恢复、返回菜单、击败敌人并重新挑战。F6直接运行该场景也支持暂停。主角和环境仍明确临时表现，原六房路线不作全局替换。

本轮补绘9张：四张跑动、一张呼吸、一张受击、两张倒下、一张起扑过渡；沿用前轮七张，合计16个不同PNG。七类动作使用不同真实姿势；跨动作复用、单姿势受击和关键帧跑动如实登记。全部1254×1254 RGBA、alpha范围0–255；原工具输出／旧图副本逐字节核对一致。使用内置imagegen，没有安装软件、接入其他图像API或通过Python修图。完整提示词、原图来源、SHA256和像素检查保存在素材同目录。

## 技术接入与规则

- `ShanXiaoVisual.sync_pose()`读取父Enemy真实状态、clock、facing和地面检测；只写SpriteFrames画面、缩放与偏移，不修改移动／伤害／生命／无敌／死亡结算。
- 前摇、有效、收招沿用现有0.50／0.30／0.65秒，实际着地后才能显示落地收招。四姿势跑动按实际水平位移推进，呈现候选步幅92.4世界像素；该数值只属于画面步态。
- 身体仍32×56，生命90、伤害12、移动165、扑击430等当前配置保持。中立美术轮廓高56世界像素；本房镜头候选1.5倍，约84屏幕像素，不冻结最终尺寸。
- 源PNG保持不变，Godot导入纹理最大512、无损、mipmaps、修正alpha边缘；依据实际纹理尺寸转换源画布枢轴。16张RGBA纹理含mipmap的理论纹理数据约21.3MiB，不等于整游戏实测峰值或性能通过。
- 唯一共享Enemy修改是实例级几何身体显示开关，默认true；此房设置false。血条和现有真实攻击预警保留，其他五种敌人与路线不变。外部新增素材、Word和原始文件移动未处理。
