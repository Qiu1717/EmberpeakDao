## 4. 本轮发现并修复的问题

1. 初始测试因主菜单不存在而红灯（退出码 1），随后建立真实工程使其通过。
2. 游戏根为 Node2D 时 Control 锚点没有正确尺寸，实际窗口显示布局错误；增加视口尺寸回归，先失败再将界面根调整为 Control，World／Actors 保留 Node2D。
3. 单脚本检查未注册 Autoload 标识；UI 改为缓存显式服务节点引用，11 个脚本均可独立解析。
4. 设置层 Tab 焦点能进入背后菜单；增加 14 次 Tab 回归，修复底层菜单可聚焦状态与关闭后焦点恢复。
5. 暂停改为 Tab 后被 GUI 导航吞掉；先复现失败，再调整输入优先级，暂停和恢复均通过。
6. 合并窗口测试首轮出现一次初始点击未生效；独立窗口重跑通过，测试入口补窗口焦点就绪等待后，完整检查重新通过，没有通过重复点击掩盖失败。
