# 阶段 2 验收报告：主角控制与基础战斗

日期：2026-10-23。基线：阶段1提交 bc0bdf3。引擎实测 4.7.2.stable.official.ed1daf0bf，GDScript、gl_compatibility。按用户最新编号，本轮对应原路线图角色战斗阶段的指定子集；完成后停止，等待阶段3指令。

## 1. 开工检查与实现范围

开工时工程已有 project.godot、App／Settings、主菜单、游戏框架、暂停、设置及真实测试，并非空目录。先读取约定、完整方案及美术／技术／工作流／测试规范，重新执行阶段1检查并通过，没有重建框架。完整主方案仅追加本轮范围记录，原有18部分、数值和规则保留。

实现 CharacterBody2D 主角：加速／减速左右移动、重力、跳跃缓冲、离地容错、平台与边界碰撞、朝向、摄像机；七状态 IDLE／MOVE／JUMP／ATTACK／DODGE／HURT／DEAD。输入沿用阶段1映射和重绑。训练实现允许空中普攻及闪避，闪避仍受统一冷却约束；此训练行为不新增成长能力或空中次数配置，后续手感评审再决定是否限制。

青锋旧剑基础三段普攻具有前摇、有效窗口和收招；有效窗口实际查询碰撞，单挥击对同目标仅命中一次，超出范围不结算。统一防御与暴击伤害公式，生命扣减、击退、0.20秒受击硬直、闪避无敌、冷却及死亡禁用动作有效。三段需在动作结束后及时再按，不提供输入缓冲自动连段。闪避可取消普攻，受击中断攻击。

训练场有地面、三处平台、边墙和静止可击退木桩；无敌人 AI。HUD 显示生命、状态和闪避冷却，提供 −10伤害、致死、重新训练按钮。重新训练真实重载场景，恢复生命、位置、动作、冷却与木桩；不处理永久资源，也不假装读取存档。原菜单、暂停、设置、返回与退出保留，继续按钮仍禁用。

- 加速、跳跃、空中动作和攻击节奏已可运行，但人工长期手感与平衡评价未验证，需用户实际试玩反馈。

- 物理手柄、正式音效听感、性能压力测试及 Windows 独立发布未验证；未安装导出模板。编辑器／引擎运行不能代替独立 exe 验收。
- 素材命名差异、主角最终造型、临时强化触发等既有未决项仍保留，不在本轮擅自裁定。
