# 动作素材生产与首轮验证

日期：2026-10-22。用户授权开发方负责三视图到动作素材的工作，可联网寻找技能；授权不要求用户自己拆层、绑骨骼或绘制动作。当前交付为方法验证，不代表全部动画制作完成。

## 1. 临时强化说明

临时强化是单次探索内的构筑奖励，例如第三段攻击附加剑气、闪避冷却减少、重击破甲增强。死亡清除，与永久大小境界及武器解锁不同。它不要求第二套经验条。

建议由战斗房奖励触发三选一：永久小境界升满后仍能在新探索获得构筑。该触发方案只是建议，用户尚未选定，主方案第 29 节待决状态不变。强化例子不是当前实现或已平衡数值。

## 2. 角色动作范围与职责

开发方负责准备动作清单、生成或绘制关键姿势、修正一致性、透明背景、统一画布与锚点、组织帧序列、制作播放预览，后续按工程阶段接入动画与判定。用户提供参考形象并决定满意的视觉效果；不要求用户学习建模工具。

## 4. 已执行的动作试验

输入：[主角三视图](../主角形象/主角.png)。采用 image_gen 内置工具，生成一组八姿势攻击图，再针对帧格间距、脚底基线与边缘残留修订一次。没有使用 Python 改图；本地检查仅读取 PNG 和 alpha，工作区文件为原样复制。

工作区保存：

- [第二轮测试图](../assets/characters/shen_jin/validation/attack_01_study_v2.png)
- [第二轮完整提示词](../assets/characters/shen_jin/validation/attack_01_prompt.txt)

检查结果：PNG、RGBA、1774×887，alpha 范围 0–255，存在真实透明区域。原样复制后的文件与工具输出字节一致。

**结论：仅作为姿势参考，未通过动画图集验收。** 宽高不能构成要求的四列两行等大方格；在估算的两条竖向分格边界上分别存在 18 与 12 个明显不透明像素，目视也发现剑刃越界。衣饰边缘仍有残留，人物尺度与脚底位置尚未充分校准。

这证明当前工具能提出参考形象的动作姿势，不能证明它能一次生成可直接切片的完整游戏动画。没有生成假预览或用平移静态图冒充跑跳。

## 5. 后续生产路线

不继续无目的反复生成整张大图。主角先按单帧或分层部件生产，统一造型、画布、脚底枢轴和武器握点后，再组装和播放；需跨视角的动作单独绘制，不只旋转肢体。

优先验证待机、奔跑和一次攻击，解决比例漂移、透明边缘、脚底抖动和剑刃路径。通过后扩展闪避、跳跃和其他角色。正式动画验收还包括动作衔接、逐帧时长、命中窗口、画面尺寸和授权记录，当前均未通过。

程序接入仍遵循原有工程阶段；本次未创建 project.godot、场景、战斗代码或下蹲功能，也没有批量制作全部角色动作。
