第一部分：项目总体设计

1. 游戏定位

《烬山问道》是一款以修仙境界突破为长期成长核心、以高操作上限的横版战斗为主要乐趣、以随机探索和装备构筑提供重复游玩价值的单机动作肉鸽游戏。

玩家扮演一名修为低微的剑修，在灵脉崩裂、仙门衰败的世界中探索秘境，击败妖兽、收集修炼资源、获得武器和功法，小境界灵气满后自动突破，大境界在存档点消耗材料突破。

随着境界提升，玩家将获得更强的战斗能力、使用更高品阶的装备、进入更加危险的区域，并逐渐揭开世界灾变的真相。

1.1 核心设计目标

游戏必须同时满足以下五个目标。

战斗有操作深度： 攻击、闪避、跳跃、技能、敌人前摇和 Boss 攻击模式都具有明确规则。

境界突破有实际意义： 突破不仅增加属性，还解锁新技能、装备品阶和探索能力。

每次探索有所不同： 随机路线、局内强化、装备词条和奇遇事件共同影响构筑。

死亡具有代价，但不否定成长： 本次探索的临时成长重置，已保存的永久境界与解锁保留。

美术具有统一识别度： 所有角色、场景、装备、技能和 UI 遵循同一套暗色手绘东方奇幻风格。

3. 世界观与剧情主线

3.1 世界背景

天地灵脉原本连接凡间与仙域，古代修士通过灵脉吸收天地灵气，建立宗门、洞天和秘境。

某场被称为“断天之变”的灾难发生后，灵脉逐渐枯竭，仙门崩塌，许多高阶修士失踪。妖兽、残魂与失控的古代法阵开始出现在各地。

玩家所在的世界只剩下破碎的修仙传承。

主角沈烬在一处无名剑冢中苏醒，记忆残缺，灵脉受损，只能从最基础的炼气境重新开始。

随着探索深入，玩家会发现：灵脉崩裂并不是自然灾害，而与古代仙门试图强行打开天门的计划有关。

3.2 主线推进

主线采用“区域探索—Boss 战—剧情线索—新区域解锁”的方式推进。

每个区域都需要完成三件事：

展示一个独特的环境与敌人生态。

通过 Boss 战获得关键道具或重要信息。

推进主角对断天之变的认知。

不采用大段连续剧情阻断战斗节奏。主要叙事通过环境、短对话、石碑、物品描述和 Boss 演出完成。

第二部分：美术总规范

4. 核心美术方向

4.1 视觉基准

项目以用户提供的参考图作为风格基准，核心特征为：

墨黑、深蓝黑、暗青蓝为主要色调。

青白色体积光与局部灵气发光。

雾气、飘散粒子和前景遮挡。

孤独的古风剑修与宏大的遗迹形成对比。

手绘笔触、明确的明暗关系和电影感构图。

少量朱红、暗金作为视觉强调色。

东方水墨意境与现代数字绘画质感结合。

不采用高饱和度网游风格，不使用大量无意义的霓虹光效，不让所有物体都拥有同样强烈的发光效果。

4.3 光影原则

远景整体更暗、更低对比度。

中景建筑具有可识别的轮廓和材质。

可战斗区域保持足够亮度，不能影响敌人识别。

关键交互物、宝箱和存档点使用局部高亮。

技能释放时短暂提高局部亮度，不要长期覆盖场景。

暗部仍然必须保留角色、敌人和平台的轮廓信息。

4.4 横版游戏的分层方式

每个场景至少拆分为以下层级：

Background_Far：天空、远山、巨大建筑剪影。

Background_Mid：远处石阶、废墟、树木。

Background_Near：与战斗区域接近的装饰物。

Gameplay：地面、平台、墙壁、碰撞体。

Foreground：前景草木、碎石、局部遮挡。

Atmosphere：雾气、浮尘、雨雪、环境粒子。

Lighting：灵脉、灯火、局部发光物。

Interactive：祭坛、宝箱、NPC、可破坏物。

前景遮挡不能长时间覆盖玩家和敌人的关键动作。

5. 角色美术规范

5.1 主角视觉设计

主角沈烬采用以下设计：

年轻成年男性剑修。

旧白色或灰白色长衫。

深色长裤和布靴。

暗红色腰带作为识别点。

宽檐斗笠或可选头部装饰。

一柄有缺口、尚未觉醒的旧剑。

衣物具有磨损、污渍和风化质感。

高阶境界通过剑气、衣物细节、灵纹与特效变化体现。

主角必须拥有独立的剪影，不直接复刻任何现有商业游戏人物。

5.2 主角动画清单

首个正式角色至少需要：

Idle：待机。

Run：奔跑。

Jump_Start：起跳。

Jump_Loop：空中状态。

Land：落地。

Attack_1、Attack_2、Attack_3：普通攻击连段。

Heavy_Attack：重击。

Dodge：闪避。

Hit：受击。

Death：死亡。

Interact：交互。

Skill：主动技能。

Breakthrough：突破演出。

关键攻击和闪避动画优先采用逐帧绘制。待机、部分移动动画可使用骨骼动画或简化逐帧方案。

6. 场景美术规范

6.1 区域 1：无名剑冢

主色：墨黑、深青蓝、月白。

核心元素：

插满残剑的荒地。

断裂的石阶。

巨型石碑。

深处的古老剑门。

从上方照射的青白色光束。

地面低雾和飘落的碎片。

6.2 区域 2：沉舟古战场

主色：灰蓝、暗铁色、少量暗红。

核心元素：

倒塌的古代城墙。

战旗和断裂兵器。

巨型战车残骸。

战场亡魂与破碎阵法。

6.3 区域 3：寒髓矿窟

主色：深蓝、冰青、苍白色。

核心元素：

冰晶矿脉。

发光的寒髓结晶。

低温雾气。

狭窄通道与坍塌矿道。

被灵气侵蚀的矿工遗骸。

6.4 区域 4：玄灯竹海

主色：墨绿、暗青、幽蓝。

核心元素：

高耸竹林。

漂浮的幽灯。

扭曲的树根。

迷雾中的剑客剪影。

不断变化的路径。

6.5 区域 5：断天仙门

主色：墨黑、冷白、青蓝与暗金。

核心元素：

悬浮石阶。

破碎的巨大门楼。

失控的灵脉核心。

破碎天空与空间裂隙。

最终 Boss 的巨大剪影。

7. 美术资产生产顺序

必须按以下顺序制作：

主角正面、侧面和背面概念设计。

主角游戏实际尺寸测试。

主角基础移动和攻击动画。

第一张场景概念图。

第一张可战斗场景的分层版本。

普通敌人和精英敌人。

Boss 设计与攻击动画。

武器图标和装备图标。

UI 与字体规范。

技能特效、粒子和环境特效。

其他区域的美术扩展。

不要在角色比例和实际显示尺寸尚未确定时，大量生成正式场景素材。

概念图不等于可直接投入游戏的精灵图。正式动画需要单独制作、拆分、校准锚点并在引擎内测试。

9.2 战斗规则

普通攻击不消耗真气。

重击具有更高伤害或破甲效果。

闪避有冷却，但在无敌时间内能够规避攻击。

主动技能消耗真气。

命中敌人可积累少量真气。

敌人攻击必须具备可辨认的前摇。

精英和 Boss 的关键攻击需要明确预警。

不同武器的攻击范围、速度和硬直必须有明显区别。

9.3 伤害计算

推荐采用：

最终伤害 = 攻击基础伤害 × 境界倍率 × 技能倍率 × 暴击倍率 × 防御系数

防御系数：

防御系数 = 100 / (100 + 目标防御值)

暴击倍率默认 1.5。所有加成统一在伤害模块结算，不能让每把武器各自实现不同的防御计算规则。

9.4 命中判定

每次攻击至少定义：

攻击开始时间。

命中生效时间。

命中结束时间。

攻击范围。

基础伤害。

击退力度。

硬直时间。

是否能够打断敌人。

是否具有破甲属性。

攻击判定应与动画同步。不得仅凭动画播放完成就自动认定命中。

11. 境界突破条件

11.1 大小境界

五大境界仍为炼气、筑基、金丹、元婴、化神。每个大境界分初期、中期、后期、圆满四个小境界。主角从炼气初期开始。

初期 → 中期 → 后期 → 圆满：击杀普通敌人、精英和 Boss 获得丹田灵气；灵气达到当前阶段门槛后自动突破，无需祭坛或突破材料。

圆满 → 下一大境界初期：灵气达到当前阶段门槛，持有一份对应材料，在灵脉祭坛手动确认突破。

每次突破消耗本阶段所需灵气并保留溢出，大境界额外消耗一份对应材料。溢出可连续满足小境界门槛，但不能自动跨越大境界。突破获得属性加成，已完成的大小境界永久保留。

11.2 材料来源

炼气圆满 → 筑基初期：镇山妖将（无名剑冢）掉落筑基灵髓。

筑基圆满 → 金丹初期：沉舟战魁（沉舟古战场）掉落凝丹玉髓。

金丹圆满 → 元婴初期：寒髓母蛛（寒髓矿窟）掉落元婴残片。

元婴圆满 → 化神初期：竹海魇主（玄灯竹海）掉落天劫道痕。

断天仙门服务于化神境终局，不新增第六大境界。精英和普通奇遇不替代最终 Boss 掉落上述关键材料。首版不另加独立突破试炼，高阶试炼在阶段 10 另行设计。

11.3 数值与保存

旧版 120 / 240 / 420 / 650 永久修为门槛不再作为有效配置。各阶段灵气门槛、分段属性与溢出上限在阶段 3–7 验证后冻结，禁止擅自当成最终数值。

第 10 节属性表保留为待验证的大境界基准，不表示四个小境界属性相同。装备品阶权限由大境界控制，不随小境界提前解锁。

化神圆满为当前境界上限；达到后不再触发突破，灵气封顶数值在阶段 10 确定。

自动小境界突破同步保存境界与灵气扣除，不得只保存属性提升却返还已消耗灵气。失败明确提示，不显示保存成功。第一次自动突破和第一次祭坛突破分别提供教学。

12. 境界与装备的关系

境界决定玩家是否能够装备某一品阶的物品。

品阶和稀有度必须分开：

品阶决定境界门槛和能力上限。

稀有度决定词条数量、词条质量和特殊效果。

境界要求决定装备权限。

高阶装备可以提前出现，但必须清楚显示要求境界。未达到要求时可以查看、收藏或登记蓝图，不能直接装备。

14.1 武器设计原则

每种武器至少需要：

普通攻击组合。

重击。

武器专属机制。

对应的动画。

命中反馈。

装备图标。

装备数据。

境界要求。

至少两种有效构筑联动。

首版只实现青锋旧剑和破山长枪。其他武器按照境界系统逐步加入。

15. 防具、饰品与消耗品

装备槽位采用简化结构：

主武器：1 个。

身法或功法：1 个。

防具：1 个。

饰品：1 个。

消耗品：有限数量。

15.2 稀有度与词条

建议采用四档稀有度：

普通：0–1 个词条。

稀有：1–2 个词条。

装备品阶不能与稀有度混为一谈。凡品武器可以是稀有品质，灵器也可以是普通品质。

第六部分：小怪、精英怪与 Boss 设计

16. 普通敌人设计总则

每种普通敌人必须有明确职责，而不只是更换外观。

所有敌人都使用统一的 AI 状态机：

Idle → Patrol → Detect → Approach → Telegraph → Attack → Recovery → Return

死亡状态独立处理。受击状态可以打断部分行为，但必须有明确的抗打断规则。

首版唯一精英敌人，承担护甲、重击破甲和灵气奖励教学，不掉落筑基灵髓。

19. Boss 总体规则

每个 Boss 至少具有：

清晰的进入演出。

两种以上普通攻击。

一种范围攻击。

一种需要跳跃或闪避的攻击。

一次阶段变化。

可辨识的攻击前摇。

死亡演出。

奖励与剧情推进。

Boss 的攻击不能随机到无法应对。攻击组合必须经过设计，并限制连续使用高伤害技能的概率。

第七部分：地图与关卡设计

21. 地图生成原则

不采用完全随机地形生成。

采用：

手工设计房间模板 + 随机房间连接 + 受控随机事件 + 固定关键节点。

这样既能保证手绘关卡质量，又能提供重复探索价值。

21.1 房间类型

普通战斗房。

精英战斗房。

宝箱房。

NPC 奇遇房。

商人房。

陷阱房。

休整房。

存档点。

Boss 房。

隐藏房。

每个房间必须有明确的入口、出口、碰撞区域、敌人生成点和交互点。

21.2 路线规则

入口到 Boss 必须始终存在可行路线。

普通战斗房至少提供一个有效出口。

每 4–6 个战斗或事件节点，原则上安排一个休整或存档机会。

精英房必须具有明显的风险与收益。

Boss 前应提供最后一次补给或调整机会。

随机路线不能要求玩家使用尚未解锁的能力才能继续。

每次探索使用随机种子，出现问题时可以复现。

地图随机性不得影响已保存的永久进度。

22. 五大区域关卡规划

区域一：无名剑冢

境界：炼气境。

主要教学内容：

移动、跳跃和闪避。

基础武器战斗。

普通敌人攻击预警。

灵气、小境界成长与局内强化。

精英战。

祭坛记录资源。

筑基突破。

流程：

入口 → 普通战斗与小境界成长 → 奇遇 → 普通战斗 → 精英战 → 灵脉祭坛记录与补给 → Boss → 返回原祭坛记录材料并筑基 → 返回驻地或解锁下一区域。

Boss 按炼气境可击败验证，不能先要求筑基。击败 Boss 后解除回程封锁，复用原祭坛，不增加第九个模板。

区域二：沉舟古战场

境界：筑基境。

主要玩法：

格挡敌人。

破甲机制。

远程攻击与冲锋敌人混合。

战场机关。

高风险战斗房。

金丹突破。

区域三：寒髓矿窟

境界：金丹境。

主要玩法：

狭窄地形。

毒素与持续伤害。

冰面、陷阱和可破坏物。

寒髓资源采集。

元婴突破试炼。

区域四：玄灯竹海

境界：元婴境。

主要玩法：

真假路径。

幻影敌人。

视觉误导与环境谜题。

剑阵与身法组合。

化神突破。

区域五：断天仙门

境界：化神境。

主要玩法：

高阶敌人组合。

多阶段战斗。

高难度房间。

终局装备构筑。

最终 Boss 与剧情结局。

23. 第一张地图的详细房间计划

首版制作以下 8 个模板：

剑冢入口：安全教学区。

残剑荒地：基础近战敌人。

断阶回廊：跳跃与地形教学。

弩傀儡祭室：远程敌人。

旧碑奇遇：首次事件选择。

裂甲山魈巢穴：精英战。

灵脉祭坛：存档、记录资源、大境界突破；Boss 战后可回访。

镇山妖将大殿：区域 Boss。

每个房间先使用占位图完成碰撞、敌人位置和相机测试，再替换正式美术。

第八部分：奇遇、事件与随机决策

24. 事件设计原则

奇遇不是单纯发奖励，而是让玩家在风险、资源和构筑之间做选择。

每个事件至少包含：

事件触发条件。

场景与交互方式。

两个以上的选择。

立即效果。

可选的后续剧情标记。

奖励或代价。

存档规则。

事件效果必须由数据配置，不要把所有事件写成一个庞大的条件判断脚本。

25. 首批奇遇事件

事件一：残剑问心

场景：插满古剑的石碑前。

选择 A：以气血换取剑意。

当前生命减少 15%。

本次探索攻击力 +20%。

选择 B：静坐感悟。

获得一小笔丹田灵气。

不获得战斗增益。

事件二：受困修士

场景：被妖藤缠绕的修士。

选择 A：救助修士。

消耗少量生命或资源。

获得丹田灵气和后续 NPC 线索。

选择 B：搜寻遗物。

立即获得灵石或装备。

失去后续帮助机会。

事件三：破阵石碑

场景：残破阵法。

选择 A：支付灵石修复。

获得一个高品质强化。

选择 B：尝试破解。

进行短暂战斗或操作挑战。

成功获得奖励，失败承受伤害。

事件四：无名商人

场景：昏暗房间中的蒙面商人。

提供：

临时武器。

药品。

局内强化。

特殊消耗品。

商品根据境界、当前局内资源和区域生成。

事件五：心魔幻境

场景：主角记忆中的古代战场。

玩法：

进入独立挑战。

在限定条件下击败心魔。

获得永久解锁或普通奖励，不替代最终 Boss 的大境界关键材料。

失败不应直接抹除已保存的境界。

事件六：灵脉裂隙

选择 A：冒险进入。

高风险战斗。

有机会获得稀有装备或大量丹田灵气。

选择 B：封闭裂隙。

获得较小的安全奖励。

本次探索不再出现该裂隙。

事件七：古井回声

选择 A：饮用灵泉。

恢复生命或真气。

选择 B：探查井底。

触发隐藏房间、敌人或装备奖励。

事件八：剑意残痕

玩家可以选择一种短期武器祝福：

迅剑：提升攻击速度。

重锋：提升重击伤害。

灵锋：提升真气恢复。

事件选择应与玩家当前武器形成有效联动。

第九部分：NPC 设计

26. 主角驻地

驻地名称：问道残庭。

它是玩家每次探索后返回的安全区域，提供永久成长、剧情推进、装备整理和任务交互。

首版只实现必要功能，不开发完整宗门经营系统。

27. 主要 NPC

27.1 沈砚舟：残存剑师

身份：曾经的高阶剑修，现已失去大部分修为。

职责：

教学与战斗提示。

解锁基础剑术。

提供武器使用说明。

随剧情揭示古代剑宗的往事。

剧情线：

从不愿提起过去，到逐渐承认自己参与过断天之变，最终帮助主角理解旧剑的真正意义。

27.2 顾长庚：流亡铁匠

职责：

装备制作。

武器蓝图登记。

消耗资源进行装备升级。

解锁装备词条重铸。

规则：

制作系统不能绕过境界限制。玩家可以提前登记高阶蓝图，但仍必须满足境界要求才能装备。

27.3 阿蘅：采药人

职责：

药品补给。

丹药与材料兑换。

提供部分探索任务。

解锁基础消耗品。

她的剧情围绕失落的药园、灵脉枯竭和修士对资源的争夺展开。

27.4 残灯婆婆：守灯人

职责：

解释存档点和灵脉祭坛。

提供境界突破相关剧情。

引导玩家阅读石碑与世界背景。

解锁部分隐藏区域线索。

她并不直接告诉玩家全部真相，而是通过暗示与选择逐步揭示世界观。

27.5 小满：失忆的残魂

职责：

提供支线任务。

解锁部分隐藏房间。

引导玩家收集古代记忆碎片。

她的故事应与主线形成呼应，而不是单纯提供奖励。

27.6 无面商人：秘境行商

出现地点：随机商人房或特定事件。

职责：

交易局内物品。

提供高风险、高收益商品。

出售一次性特殊道具。

提供少量随机事件。

无面商人的商品可以随着玩家境界变化，但不能让付费式或无限刷钱式机制破坏平衡。

28. NPC 任务规则

每条主要 NPC 任务线至少包含：

初次相遇。

一次探索中的任务。

一次剧情推进。

一次永久奖励或解锁。

一个可以记录在存档中的任务状态。

任务进度保存在永久档案中。已完成的关键任务不应因为死亡而回退。

第十部分：肉鸽成长与死亡机制

29. 成长与资源数据

29.1 丹田灵气

原“战斗经验”和“修为”统一为丹田灵气，不再额外维护独立经验等级条与永久修为条。普通敌人、精英、Boss 均提供灵气，事件可通过资源配置发放灵气。

灵气分祭坛已记录余额和未记录新增余额。死亡保留已记录且未消耗余额，丢失未记录部分。用于突破的灵气不能因死亡或加载旧快照返还。

29.2 局内构筑

临时强化、掉落装备实物和词条属于本次探索，死亡清除。已解锁武器、已登记蓝图永久保留；新探索可使用已解锁基础武器，不等于保留掉落装备实物。

原“经验升级三选一”不再隐含独立经验计数器。临时强化触发方式（随小境界突破或战斗房奖励）在阶段 6 实施前确认，本次不擅自冻结数量和频率。

29.3 灵石与材料

灵石和突破材料均分已记录与未记录。祭坛记录后死亡保留；祭坛后新增但未记录的部分死亡丢失。在同次祭坛交互可先记录材料，再消耗一份用于大境界突破。

29.4 永久状态

已完成的大小境界、已解锁武器、已登记蓝图、已保存 Boss 和任务进度、已记录资源保留。自动突破仅提交必要的成长与消耗，不把其他未记录资源变成永久资源。

30. 存档点机制

灵脉祭坛记录灵气、灵石与材料，保存档案与探索继续位置，执行大境界突破，更换符合要求的装备，并恢复部分生命与药品。小境界满灵气自动突破，不需要返回祭坛。

退出后可继续最近成功保存的探索快照；快照保存不等于资源永久记录，见第 36 节。死亡结束本次探索并返回问道残庭。

首图 Boss 后须回访同一祭坛。关键材料在未记录前死亡丢失后，可在后续新探索再次击败对应 Boss 获取；永久首杀剧情奖励单独结算，不得形成突破死锁。

31. 死亡流程

触发死亡 → 停止输入与战斗判定 → 死亡动画 → 探索总结 → 提交死亡结算 → 清除未记录资源和局内快照 → 返回问道残庭 → 下次探索生成新种子。

保留：已完成大小境界、已记录且未消耗的灵气／灵石／材料、已解锁武器、已登记蓝图与永久剧情进度。

清除：未记录灵气／灵石／材料、临时强化、掉落装备实物、局内事件状态。

死亡结算与旧局快照失效同步提交，加载不得把已结束探索恢复成活跃探索。

36. 存档实现要求

运行期分别管理 ProfileState、RunState、Settings。永久档案和局内快照使用同一版本化存档封套原子提交，防止两个文件只写成功一个；设置独立保存。

永久档案：大小境界、已记录灵气／灵石／材料、武器解锁、蓝图、Boss 首杀、NPC 任务、设施与存档版本。

局内快照：run_id、区域与房间、安全恢复点、地图 seed、各随机流状态、房间清理与开门状态、已领取奖励标识、生命与真气、装备、临时强化、未记录灵气／灵石／材料、事件状态。

保存边界：祭坛记录资源并提交继续快照；小境界自动突破提交境界、消耗及关联快照；大境界突破提交境界、灵气与材料消耗及快照；死亡提交永久档案并将局内快照失效。

技术决定：自动突破额外产生一致继续快照，重启从对应房间安全点恢复，不恢复在攻击命中帧；死亡仍返回驻地。快照中的未记录资源仍会因死亡丢失，不构成自动记录。

灵气优先消耗未记录余额，再消耗已记录余额，后者同步扣减永久余额。不得通过死亡或重启返还已消耗余额。账本例子见 TECH_DESIGN.md。

临时文件写完再替换正式存档，保留上一份有效备份。加载检查版本、必要字段、类型和标识；旧版本显式迁移。保存失败明确提示，不显示成功。

奖励唯一标识至少区分 run_id、来源实例和奖励类型。同一交互、死亡或读档不能重复领奖。Boss 首杀奖励永久唯一，关键突破材料可在新探索重新击杀获取。

单人离线存档不承诺阻止用户手动复制旧存档；测试覆盖游戏自身操作造成的重复领取。本阶段仅有设计，尚无真实历史存档或迁移实现。

第十七部分：项目风险与控制措施

41. 主要风险

风险一：美术工作量失控

措施：

先做主角、一个场景和一个敌人。

验证实际显示尺寸。

建立复用材质和分层规范。

后续区域采用统一的制作模板。

风险二：战斗手感不好

措施：

在正式美术完成前使用占位素材测试。

先调整攻击时间、闪避距离和敌人前摇。

不要通过堆叠数值掩盖动作问题。

风险三：系统过多

措施：

首版不做联网、宗门经营、宠物和复杂炼丹。

任何新系统必须说明其对核心循环的贡献。

先完成垂直切片，再增加长期内容。

风险四：存档逻辑复杂

措施：

从早期就区分永久状态与局内状态。

所有奖励结算都必须有唯一标识或幂等保护。

突破、Boss 奖励和永久解锁都必须进行回归测试。

风险五：Codex 一次生成大量无法运行的代码

措施：

每阶段只交付有限功能。

先检查工程再修改。

每阶段必须实际运行。

未通过验收不进入下一阶段。

第十八部分：最终交付定义

项目不能以“代码已经生成”作为完成标准。

首个可玩版本必须达到：

能够启动。

能够操作角色。

能够进行战斗。

能够获得丹田灵气、自动突破小境界并取得临时强化。

能够击败精英与 Boss。

能够在存档点记录资源并使用 Boss 材料突破大境界。

能够完成炼气到筑基的突破。

能够正确限制高阶装备。

能够在死亡后清除局内成长。

能够保留永久境界和永久解锁。

能够保存、退出、重启并继续游戏。

能够导出 Windows 独立运行版本。

完整版在此基础上扩展五大区域、更多武器、敌人、NPC、奇遇和高阶境界。

最终目标是交付一个可以独立运行、可以持续扩展、具有统一美术风格、具有完整战斗与成长循环的单机动作肉鸽游戏，而不是一组无法整合的功能原型。

最终开发原则：先完成最小但完整的游戏体验，再扩展内容；先验证战斗和成长，再投入大规模美术生产；每个阶段都必须有明确的交付物和验证证据。阶段 0–1 以文档和美术验证为主，阶段 2 起要求运行工程；不得用阶段 0 的文档检查代替游戏测试。
