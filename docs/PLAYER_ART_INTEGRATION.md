# 主角美术静态接入

2026-10-23，用户要求先将已有主角角色美术加入游戏。本次范围为静态造型接入，不批量制作完整动作，不进入阶段4。

## 实施范围与文件

- 输入主角形象/主角.png：实际RGB1448×1086、带灰底三视图。旧validation攻击图集仍不合格，保留原位，不用于角色切片。
- 使用内置imagegen，以用户三视图为唯一造型参照制作一张透明侧视工作图，保留青白衣饰、长发和饰物。原图不改，衍生素材另存assets/characters/shen_jin/static_v1/，记录完整提示词、来源和像素检查。
- 修改scenes/player/player.tscn挂载真实Sprite2D，scripts/player/player.gd仅更换绘制、按朝向翻转和状态颜色提示。静态图不宣称是完整动作；不修改生命、速度、碰撞、剑伤害、攻击窗口或闪避无敌。
- 所有复用主角场景的位置生效：主路线、剑术训练场、山魈美术样板。更新对应UI说明、README和ART_DIRECTION的当前状态，不覆盖历史记录。
- tests/test_player_art.gd检查真实纹理、脚底／比例／翻转、三类场景的接入、状态反馈和重开；纳入现有回归。全程保留用户外部新增文件及原素材移动。

## 验收

先写真实玩家场景缺少Artwork节点的失败测试，再接入素材并运行。检查真实alpha、完整轮廓、原图不变、屏幕尺寸、脚底不因翻转偏移；实际窗口确认角色可见、状态提示准确，战斗数值和物理逻辑不变。执行完整工程回归，未执行或未通过项如实登记。

当前仅单张侧视素材：移动、跳跃、攻击、闪避、受击与死亡仍无完整逐帧动作。原服饰与方案旧衣描述的差异沿用既有记录；用户本次指令授权采用现有图做接入候选，不等于冻结永久服饰方案。

## 实际交付与来源

## 已知限制与未验证

- 当前仅静态接入；完整跑跳、握剑挥动、闪避、受击与倒下动作尚未制作，正式青锋旧剑外观和握点尚未校准。
- 完整轮廓未截断，但头顶15、脚底10像素留白没有达到制作要求的40像素，局部白／青边缘碎点仍需精修。两次制作请求仅首张完成并选用；精修长时间未返回后取消等待，未计为交付。
- 左右镜像会翻转不对称饰物；正式服饰、显示比例与持续操作手感尚未由用户验收。
- 没有新安装软件、技能或依赖；游戏存档、阶段4、独立Windows发布和长期性能本轮未验证。
