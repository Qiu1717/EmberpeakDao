# 动作帧与原图关卡重建

2026-10-23，用户明确要求加入主角与怪物动作帧，并把现有地图做成实际关卡，不能只当屏幕背景。上一轮静态接入只完成展示，不满足本轮目标。本轮承接e2f5733，在codex/animated-playable-map分支执行，完整设计方案仍为唯一玩法基准。

## 实施决定

- 不改生命、伤害、速度、闪避无敌和Boss阶段数值。现有山魈动作保留；主角、尸兵、游魂、傀儡、精英及Boss制作独立姿势帧，绑定真实状态和攻击阶段。少量关键帧先达到可玩，不把单图位移当跑步，不提前声称正式美术完成。
- 六张用户地图按原图世界坐标建设实际地面／石阶／平台／断桥，图中可走表面与碰撞对齐；镜头随角色在世界中移动，移除原路线底部统一平面、蓝色占位平台及屏幕墙纸方式。图片本身仍作为原始手绘材质，不删除原图；Godot节点、Polygon2D纹理／UV及碰撞体负责可走层、遮挡与关卡。
- 关卡制作判断：前景连续地面与明确断阶、孤岛作可走路线，远山／远景遗迹不作可走地形；断阶跨越须以现有-600跳跃和280移动实际测试，不通过改数值掩盖不可达。
- 保留训练场和平面山魈样板作为既有战斗回归环境；六房主路线独立换成实际地图。跌出地图接现有测试死亡／重开流程，不开发正式存档。
- 不新增NPC交易、装备玩法、随机地图或下一阶段系统；原三视图、已生成动作和用户未跟踪文件均保留。

## 分工与文件边界

1. 地图：scripts/world、scenes/rooms及独立map脚本／布局数据，tests/test_route.gd和新地图专项。完成原图表面、世界相机、出生点、实体门、清场换房和坠落处理；不改动画脚本。
2. 动画：scripts/art中的帧播放、player/enemy接入、scenes/player，以及动画专项和旧主角美术测试。制作素材由主代理统一处理，独立目录assets/animations/<actor>/，不改地图。
3. 集成：素材像素／切片／锚点QA、manifest、test_all_art适配、回归运行器、文档、最终图形运行和只读审查。不同代理不并发启动图形测试或改同一文件。

## 验收门槛

- 主角跑动姿势确实变化，三段攻击有效帧与已定判定同步；跳跃、闪避、受击与倒下使用对应姿势。六种敌人都有动作变化，Boss模式与转阶段可读。
- 六房身体实际落在图中地面；断阶至少存在完整可达跳跃路线，不能只在图片前的旧平面上走。相机移动时地形与碰撞保持重合。
- 门在未清场时真实阻挡，清场解锁后能按交互键前进、返回祭坛，死亡与重开正常。训练／样板原有战斗数值回归不变。
- 原图／选用生成PNG保留；实际检查alpha、切片边界、姿势差异、游戏比例、左右脚底与暂停冻结。无效帧不计交付，不称未执行的测试通过。
- 最终运行完整headless及窗口测试，保存实际截图和可观看动作预览；列出所有未完成和未验证项后停止。

## 实际交付

1. 主角12姿势：待机、两姿势移动、跳跃、攻击蓄势、三段有效姿势、闪避、受击、两姿势倒下；攻击收势复用中立。五种敌人中，尸兵／游魂／傀儡／裂甲山魈各12姿势，镇山妖将16姿势，共新增76姿势；山魈幼体保留原16张图。不是完整高帧数动画，待机、跳跃、闪避等仍有单姿势。
2. Player ArtworkController和Enemy Visual实际播放AtlasTexture切片；读取真实移动位移、攻击时钟、受击、转阶段、死亡和朝向。三个主角入口共用表现，不再按静态图滑动。源朝向混杂的图逐姿势校准，不改身体碰撞与战斗数值。
3. 六房使用用户1672×941原图世界坐标，建立Polygon2D材质／UV、实际地形碰撞、锁门、出生与交互点、跟随镜头、断阶落坑及死亡。远景Sprite2D保留原画天空／建筑，地形贴图与碰撞重合；没有另造一层旧平地。当前是原图可走轮廓重建，不是全部建筑拆件或完整视差分层。
4. 原26图图鉴与素材保持，NPC／装备仍仅展示。主方案、主角／敌人数值Resource没有改动，未实现阶段4系统，没有安装软件、插件或依赖。

## 素材与像素检查

六份选用PNG均为工具输出原字节，真RGBA，alpha范围0–255；五份1448×1086，Boss1254×1254。Godot导入上限2048与mipmaps开启，实际大小不被缩小。各自qa_pixels.json保存整图SHA256和所有选用pose的像素哈希；76份像素区域彼此不同，不把重复同图当新动作。

生成输出不全是严格等格。尸兵末行、游魂各行、精英行界及Boss部分武器沿实际透明间隙配置可变region，不裁掉武器，也不包含相邻身体。明显alpha（≥32）轮廓最小边距：主角2、尸兵8、游魂4、傀儡16、精英4、Boss6源像素。边距达标仅证明切片边界，不代表衣饰、辉光和动作质量完成。

另实际校验26张图鉴运行副本与原始用户文件SHA256均符合原catalog记录。没有覆盖原始三视图／概念图、静态工作图或旧试验图；用户移动的Boss／精英原图位置及其未跟踪文档不纳入本轮改动。生成服务曾连接失败或取消等待，均不计成功图集；首图串帧与带辅助边框的布局未作为运行图采用。
