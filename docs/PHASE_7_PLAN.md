## 执行顺序、文件和门禁

1. 依据TEST_PLAN核实际工程／场景／入口／模板，实际跑阶段6基线；保持已有设计、美术、数值和存档规则。
2. 新增tests/test_release_stability.gd，真实循环菜单、探索、驻地、模态；记录节点／孤儿节点／信号连接、死亡敌人和弹体清理、空闲写盘次数与保存耗时。发现问题先重现再做最小修复，不凭猜测清理缓存或重构。
3. 新增tests/benchmark_runtime.gd，在当前Windows图形环境执行有明确时长的持续采样，记录帧间隔、处理耗时、内存／节点及房间切换。测试夹具和硬件、时长、样本、局限全披露，不把五分钟当数小时耐久或目标机达标。
4. 完善export_presets.cfg、project.godot、assets/ui/app_icon.svg，配置Windows Desktop x86_64、启动场景、窗口／图标及明确打包范围。现有美术、动态load引用的JSON／PNG／场景必须保留，排除测试／源码参考板原目录／私有构建产物与文档。
5. 新增scripts/tools/build_windows.ps1执行实际--export-release并检查退出码、日志、exe／pck。缺模板记录真实失败，不把编辑器exe复制成发布程序。可执行的资源打包／PCK检查属于资源验证，不冒充独立Windows发布。
6. 修改tests/run_checks.ps1仅增阶段7专项、日志路径并保留原全部回归。执行完整-Windowed、审查必要修复、更新docs/PHASE_7_REPORT.md／RELEASE_NOTES.md／WINDOWS_RELEASE.md、README／TEST_PLAN／AGENTS等。
