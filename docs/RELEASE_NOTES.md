## 当前可用内容

无名剑冢八模板十节点探索；青锋旧剑／破山长枪及重击；四种普通敌人、裂甲山魈、镇山妖将；清场三选一、旧碑奇遇、宝箱／掉落、无面商人；背包与六种武器／装备、境界限制；炼气自动小突破和祭坛筑基；已记录／新增资源、死亡清局、蓝图／武器永久解锁、版本化本地存档和继续；五NPC基础服务、随身药品、Boss后祭坛结算及临时问道残庭。

阶段7修复：半清场时死亡敌人节点释放后仍保留0生命／护甲来源；继续后再次保存同一房间也保持正确，不复活已死敌人或重复发奖。没有更改玩法、敌人基准、装备效果、掉率或灵气门槛。

回归实测：79份脚本解析及完整窗口／无窗口套件通过，新增稳定性各62项。最终PCK已排除内部生成／QA记录，并完成隔离资源与流程检查。当前独立Windows exe仍缺模板；五分钟样本仍出现最大262.709ms长帧，完整快照同步写入约70–76ms，不能宣称发布性能已达标。

## 操作与流程

| 操作 | 默认输入 |
|---|---|
| 移动／跳跃 | A、D／Space |
| 普攻／重击 | J或左键／K或右键 |
| 闪避／药品 | Shift／E |
| NPC、宝箱、祭坛、出口 | 靠近后F |
| 暂停／关闭面板 | Esc |

按键可在设置重绑。主动技能Q尚未开放；药品最多2次，每次恢复最多35生命，入口阿蘅和原祭坛可补给。

从主菜单开始探索，战斗清场选强化，靠近出口选路；旧碑和商店有真实结果。击败精英后到原祭坛记录，挑战Boss后从左门回同一祭坛。炼气圆满、灵气足且有筑基灵髓时手动筑基。登记要保留的蓝图后，可以在祭坛记录资源并结束探索返回驻地。死亡后丢未记录资源和局内强化／实物，已保存境界和未消耗永久余额保留。

当前完整搜集第一局收益274灵气，全部突破消耗280，需先记录后继续下一次探索积累；数值仍待平衡，不承诺首次Boss后立即筑基。新游戏保留永久档案，不是清档按钮。正常退出只有最近成功快照可继续，未到保存边界的进展不保证恢复。
