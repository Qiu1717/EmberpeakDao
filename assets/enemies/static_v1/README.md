# 第一地图敌人静态美术候选

五种敌人各一张透明单姿势：腐甲尸兵、断刃游魂、灵弩傀儡、裂甲山魈、镇山妖将。均通过内置imagegen从用户原设定图提取；本目录不含完整移动、攻击或死亡动画。山魈幼体直接复用已有playable_v1动作，不再生成替代图。

每张PNG保留工具输出原始字节；各id_prompt.txt为实际提示词，generation_sources.json记录工具输出路径和原图，qa_pixels.json记录原图／输出SHA256、RGBA与alpha范围、可见边界。没有通过代码改像素、清底或伪造alpha。

Godot原生无损导入最大512，启用mipmaps和fix_alpha_border，源图不改。manifest.json记录源画布、脚底枢轴、可见高度和实际朝向；Sprite按现有敌人碰撞高度显示，朝向不同分别处理镜像。受击着色、死亡随原Enemy淡出，预警与血条保留；美术不决定AI、伤害、硬直或碰撞。

已知限制：原提示要求统一朝左与50像素留白，实际没有全部满足。尸兵／游魂原生朝右，傀儡／精英朝左；Boss为偏正面的侧转姿态，按朝右候选处理。尸兵底部约8像素，傀儡顶部3、底部1像素，Boss右侧约3像素；当前可见部件仍需正式轮廓和留白复核，不能称最终美术验收通过。精英骨甲、毛发与Boss武器仍有生成细节漂移；左右镜像会翻转不对称装饰。所有正式动作、独立武器握点和场景建筑均留待后续。
