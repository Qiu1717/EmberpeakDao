# 山魈幼体：扑击动作样片 v1

状态：**技术播放已验证，正式美术未验收，未替换游戏敌人。**

参考用户的山魑幼体.png，制作7张不同姿势的透明PNG；播放8帧槽，最后一槽复用第1张。画布均1254×1254，左朝向，公共枢轴(800,1205)。不把复用帧算作独立绘图，不将移动静态图当成逐帧动作。

在项目根目录运行独立预览：

```powershell
& 'E:\Godot\bin\godot.bat' --path . res://scenes/art/shan_xiao_pounce_preview.tscn
```

支持暂停、上一帧／下一帧、正常／半速、重播、关闭预览位移；Space暂停，方向键逐帧，Esc退出。放大图与当前56像素高度并列显示，下方是8帧槽缩略图。循环间有0.7秒停顿后位置复位，该停顿不计入动作的1.45秒。

|文件|用途|
|---|---|
|raw/frame_01.png至frame_07.png|内置imagegen生成结果的字节一致副本，未裁切、缩放或修改像素|
|manifest.json|帧序、时长、画布、枢轴、朝向和待验收状态|
|qa_pixels.json|逐图RGBA、alpha、轮廓边距及SHA256实测|
|generation_requests.json|原始生成请求，含完整提示词、参照顺序和重试说明|
|provenance.json|输出来源、字节一致核对及制作范围|
|.gdignore|样片不参加游戏运行素材导入；独立预览直接读取原图|

动作分段读取现有测试配置的0.50秒前摇、0.30秒有效、0.65秒收招；未修改游戏配置，也未把这些临时平衡值升级为最终设计。现有56像素仅作对照，不冻结正式美术尺寸。

已知问题：低帧数仍显跳跃，脚底、白鬃和饰物有帧间漂移；部分轮廓最小边距9像素，未满足提示词20像素要求，弱透明像素也仍需检查；56像素下细节不清。该样片不代表完整移动／受击／死亡动画，不代表其余五种敌人或NPC动作已完成。需继续修正、补过渡帧和用户视觉审阅，再决定正式接入；当前不修改AI、攻击判定或碰撞。
