# 山魈幼体：单房可试玩美术候选 v1

状态：已接入独立战斗房，等待用户审阅；不是全角色正式美术验收。

从主菜单点击“山魈美术样板”，或在Godot打开scenes/art/shan_xiao_art_room.tscn并按F6运行。移动／跳跃／攻击／闪避沿用设置，Esc暂停；界面可重新挑战、返回菜单和显示身体碰撞。

16张透明原始PNG：沿用已检查的7张扑击姿势，新增4张跑动、1张呼吸、1张受击、2张倒下、1张起扑过渡。idle两帧、run四帧、telegraph三帧、airborne三帧、recovery三帧、hurt一张姿势、death两帧；跨动作复用明确保留，不把帧槽总数当成独立绘图数量。待机与跑动为简化关键帧方案，受击为单姿势短暂保持，不冒充丰富的逐帧受击动画。

- manifest.json：姿势、源画布枢轴、时长、候选世界比例与跑动步幅。
- generation_requests.json：本轮9次内置imagegen完整提示词和参考路径。
- provenance.json：原始参考、新9图工具输出、字节一致性与来源；旧7图来源引用前一试验目录。
- qa_pixels.json：16图实际RGBA／alpha／轮廓边距／SHA256。
- raw/*.png.import：Godot原生无损压缩、最大512、mipmaps和fix_alpha_border；仅导入处理，原PNG像素不改。

原图均1254×1254；表现根据导入纹理实际尺寸换算枢轴，原中立轮廓高56世界像素。独立样板镜头1.5倍，约84屏幕像素，不改变实际32×56身体碰撞。左右翻转围绕敌人根节点；物理位移只来自Enemy，跑动按实际位移推进。前摇／有效／收招跟随当前配置0.50／0.30／0.65秒；实际着地之前继续显示腾空姿势，不由素材强制落地。

现有AI、生命90、伤害12、速度和攻击判定保持不变；原六房路线仍为临时几何角色。本目录只在独立样板中使用，未经用户审阅不批量替换。显示身体碰撞可检查衣摆、长臂超出身体矩形的范围；装饰轮廓不等于可受击身体。
