# 沈烬：静态侧视图接入 v1

一张静态侧视角色图，来源于用户主角三视图的中间侧面。主角原图完整保留，旧攻击图集未使用；本目录不是完整动画集。

side_idle.png为内置imagegen生成输出的原样副本，保留青白衣饰、长发、饰物和鞘中佩剑。generation_prompt.txt保存实际制作提示词。cleanup_prompt.txt是后续边缘精修请求：长时间未返回，已取消等待，**不算完成，也不是当前PNG的制作结果**。

主路线、剑术训练场和山魈美术样板均复用scenes/player/player.tscn的Artwork精灵。源PNG1254×1254，RGBA真实alpha；可见轮廓约1229源像素高，脚底枢轴候选(590,1244)，显示高56世界像素。Godot无损导入最大512，启用mipmaps／fix_alpha_border，按导入尺寸换算缩放和枢轴；原PNG像素不改。镜像围绕脚底，24×56物理碰撞及战斗配置不变。

移动／跳跃／攻击／闪避时仍保持单张姿势，只翻转朝向；受击、闪避和死亡使用明确的状态颜色。没有将单图平移冒充跑动，或宣称挥剑／死亡动作已经制作。原攻击范围示意与有效窗口保留，不等于已经绘制了持剑挥动。

已知问题：提示词40像素留白未完全满足，可见头顶15、脚底10像素；完整轮廓未截断，但局部白／青边缘碎点仍需精修。鞘中佩剑和服饰细节沿用参考，正式青锋旧剑独立造型／握点及完整动作另行校准。左右镜像会翻转不对称装饰，最终服饰与显示比例未冻结。

qa_pixels.json记录实际格式、alpha、轮廓边界与SHA256；provenance.json记录原图、工具输出与字节一致性。此技能许可不作为用户原图或生成素材的权利结论。本次没有额外软件或运行依赖。
