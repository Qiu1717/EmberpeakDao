# 基础动作关键姿势候选

用户授权从现有第一地图与主角素材制作动作。主角、腐甲尸兵、断刃游魂、灵弩傀儡、裂甲山魈各12个独立姿势，镇山妖将16个，共76姿势；山魈幼体继续读取原playable_v1的16张图。NPC本轮没有动作制作。

每目录含工具原字节sheet.png、Godot导入配置、实际切片manifest.json、只读像素检查qa_pixels.json、来源provenance.json及实际提示词。所有图均真RGBA透明；五张1448×1086，Boss1254×1254。Godot保留原尺寸（上限2048），启用mipmaps。原始用户图与旧静态工作图均保留，没有用Python改图。

图集不是全部严格等格。原生AtlasTexture沿实际透明间隙切片，不得只按4×3／4×4机械分格。尸兵末行、游魂、精英行界和Boss部分武器使用可变矩形，枢轴均为当前切片局部坐标。源姿势左右不一致时以pose.native_facing校准。身体比例依据待机轮廓统一，倒下不拉高；时长读取实际战斗状态，不由图像控制伤害。

首轮图集有串帧未采用；辅助边框清理及重新布局后选用当前版本。曾有生成连接失败和取消等待，不计成功结果。当前最小明显alpha（≥32）边距：主角2、尸兵8、游魂4、傀儡16、精英4、Boss6源像素。仅证明当前切片内有完整明显轮廓及空白边距，不代表边缘、造型和连续动作都通过。

这些是少量关键姿势候选：双姿势移动、单姿势待机／跳跃／闪避／受击、阶段姿势攻击和两姿势倒下。仍需足相、挥剑路径、衣饰／武器一致性、透明碎点、镜像与中间帧精修。未作最终角色尺寸／审美／连续手感验收，不称正式完整逐帧动画。
