# 烬山问道

Windows PC 单人离线、手绘国风 2D 横版修仙动作肉鸽。引擎 Godot 4.7.2 stable，GDScript，gl_compatibility。

当前为0.1.0-rc.1首图候选版本：沿用八模板探索、两武器、六敌、装备、突破与存档，以及五NPC服务、药品、Boss后结算与临时驻地。阶段7补充稳定性／窗口性能和打包检查，并修复半清房已释放死敌的快照记录；未改玩法或数值。Windows独立exe导出因缺匹配模板受阻，不宣称发布成功，详见[阶段7报告](docs/PHASE_7_REPORT.md)。

主角、六种敌人沿用已有动作候选；八个模板有实际碰撞，旧碑新增原图地形，弩室暂复用荒地。建筑拆件、动画补帧和正式美术仍待制作。“固定路线测试”“剑术训练场”“山魈美术样板”和26张原图图鉴保留，方便独立验证；下文早期素材接入说明为历史记录。

唯一设计基准：[完整开发方案](docs/GAME_DEVELOPMENT_PLAN.md)。[开发约定](AGENTS.md)、[阶段6报告](docs/PHASE_6_REPORT.md)、[阶段7计划](docs/PHASE_7_PLAN.md)。本轮完成后停止，等待最终交付确认，不自动开发其他区域。

## 运行

在项目根目录打开 PowerShell。若会话中 godot 命令未刷新，直接使用现有绝对路径：

```powershell
& 'E:\Godot\bin\godot.bat' --path .
```

打开编辑器：

```powershell
& 'E:\Godot\Godot_v4.7.2-stable_win64.exe' --editor --path .
```

首次打开或新增运行资源后导入：

```powershell
& 'E:\Godot\bin\godot.bat' --headless --path . --import
```

引擎无需重装。本机尚无匹配导出模板，当前从编辑器或引擎运行；尚未生成独立 exe。

Windows构建命令为 `pwsh -NoProfile -File scripts/tools/build_windows.ps1`，当前实际执行因模板缺失失败。导出配置、所需模板路径、PCK与exe区别及后续独立运行验收见[Windows发布说明](docs/WINDOWS_RELEASE.md)，操作与已知限制见[候选版本说明](docs/RELEASE_NOTES.md)。资源包成功不等于独立程序已发布。

## 菜单与设置

主菜单可开始新游戏、打开设置和退出；无游戏存档时继续不可用。游戏场景中点击暂停或按暂停键，菜单提供恢复、设置、返回主菜单和退出。返回菜单会清除暂停状态，窗口关闭也走统一退出流程。

设置包括总音量、音乐、音效、窗口／全屏、1280×720／1600×900／1920×1080 窗口分辨率、垂直同步和键位重绑定。全屏使用显示器尺寸。调整后点击“应用并保存”；未应用即关闭会放弃修改。“恢复默认”先修改面板草稿，再由应用确认。

点击键位按钮后按新键，Esc 取消；冲突按键不接受。重绑只替换键盘绑定，鼠标和手柄默认映射保留。Esc 在设置界面始终可关闭该层；暂停键重绑后游戏内按新键操作。控件可用 Tab 和方向键导航，设置开启时不能选中背后的菜单。

设置独立保存在 `user://settings.cfg`，本项目 Windows 默认位置为 `%APPDATA%\EmberpeakDao\settings.cfg`。它只保存用户偏好，不是角色档案或探索存档。Music、SFX 总线已配置，目前没有音乐与音效素材。

## 成长、装备与存档

“开始新游戏”表示以当前永久档案开始新探索，不会删除境界；它先使被放弃的旧探索在磁盘失效。继续按钮只在有有效探索快照时可用。自动小突破、祭坛保存／记录／大突破、蓝图登记、交易和死亡使用一致封套提交；未到保存边界的战斗进展不保证退出后恢复。

HUD显示境界、丹田灵气门槛、已记录与新增余额、真气及当前武器。“本局行囊”可查看材料、已记录材料、装备栏和实物详情；点击装备进行穿卸。品阶、稀有度与境界要求分开，高境界装备可以拾取但不能越境界穿戴；宝箱可能提供回灵玉佩或玄纹法衣供筑基后使用。换装不免费回血，残剑坠只增强第三段，回灵玉佩实际增加真气恢复。当前无主动技能，普通攻击和重击不耗真气。

原灵脉祭坛中央按F可恢复生命与真气，并打开：记录资源并保存、突破大境界、只保存快照、整理装备／登记蓝图。记录后未消耗余额死亡保留；只保存快照的未记录资源仍会因死亡丢失。登记已有实物蓝图可永久保留，长枪蓝图同时解锁后续新探索的基础长枪；蓝图不是掉落实物保留，也没有假装已实现装备制造。

默认存档为 `user://save_game.json`，本机通常为 `%APPDATA%\EmberpeakDao\save_game.json`，含版本、永久档案和完整探索快照；设置仍独立。临时文件和有效备份用于异常恢复。损坏恢复明确提示备份版本，并停用备份中的旧探索；不兼容版本保留原件，不自动覆盖。写入失败显示原因，成长不发布；死亡保存失败必须重试成功后才能正常离开。测试通过环境变量 `EMBERPEAK_SAVE_PATH` 使用私有档，不触碰玩家正式档。

首图测试成长止于筑基初期，后续境界门槛未伪造。长枪和重击动画暂借剑术候选帧，玄纹法衣无新图标；正式姿势、美术与独立Windows导出仍待后续。

## 肉鸽探索操作

安全入口靠近三个临时NPC交互点按F：沈砚舟可唤出无奖励练习木桩，顾长庚可登记所持蓝图，阿蘅免费补齐2次药品并保存当前探索。E（可重绑）每次恢复最多35生命，满血／硬直／攻击／闪避时不消耗；祭坛休整也补齐药品。补给存档会保存当前未记录资源快照，但不会把它们永久记录。制作、升级、重铸、丹药兑换和个人任务尚未开放。

靠近右门按 F 打开前路选择，左门可回已访问的房间；战斗中两端实体门锁住。首次清场选择一项强化；Esc 可暂时关闭，按 F 重开仍是同一组候选，选完才可离开。地图有3种连接拓扑、商店／奖励前后交换共6种布局，不是无限随机地形。

旧碑中央按 F 触发“残剑问心”：消耗当前生命15%换本局攻击，或直接获得灵气。无面商人中央按 F 购买治疗、攻击加成或一次替劫符，库存本局有效；缺钱或满血治疗不会扣款。奖励房中央按 F 打开一次宝箱。敌人奖励自动收取，HUD 提示实际所得，右下“本局行囊”显示材料、装备和种子。战斗中也可查看行囊，界面期间世界暂停。

精英 → 原祭坛 → Boss 为固定关键路线；击败Boss后回原祭坛记录材料并筑基。死亡或重新探索清空局内内容，永久档案按上节保留；死亡总结列出丢失与保留。普通暂停／设置仍使用Esc。

Boss后在原祭坛选择“记录资源、结束探索并返回驻地”，会先可靠保存资源与旧局失效，再清除局内强化和实物；请先登记要保留的蓝图。失败可原地重试。死亡总结也可返回问道残庭。驻地使用入口地形作为明确临时资源，包含实际角色／碰撞、永久进度、新探索和继续；进入驻地本身不覆盖现有快照。

当前测试门槛总计280灵气；不额外刷奖励时，即便完整探索两间入口战斗房、宝箱并选感悟，总计274，首次Boss后还差6。可在祭坛记录后结束，再探索积累；无需再次获得已有记录材料才能突破。此节奏仍待平衡，本轮没有暗改数值或宣称自然一局筑基。

## 无名剑冢固定路线（独立回归入口）

剑冢入口 → 残剑荒地（山魈幼体／腐甲尸兵）→ 断阶回廊（断刃游魂／灵弩傀儡）→ 裂甲山魈精英战房 → 灵脉祭坛 → 镇山妖将Boss房。普通攻击、移动、跳跃与闪避用下表按键。敌人上方及HUD显示生命、预警、收招和阶段；金色区域是预警，红色是攻击，收招期间可反击。

战斗房清场后红色实体门解除封锁，靠近右侧门按F前进，靠近左侧门按F返回；交互键可重绑。Boss被击败后从左门返回原祭坛，已清场房不重新刷怪或发奖励。中央祭坛附近按F可做测试休整恢复生命，当前没有资源记录、存档或突破。死亡后点击“重新开始路线”会重置本次路线，不读取永久档案。

“敌人资料卡”可查看附近存活敌人的完整概念板，图片不参与动作播放。山魈扑击、尸兵蓄力重劈、游魂快速双击、灵弩后撤射击；精英有甲减伤、60%增加砸地，Boss55%转阶段并新增连击及可跳过的地面冲击波。共享主角已支持K／右键重击与实际削甲、真气恢复；主动技能尚未开放。固定路线不提供成长与装备系统，完整服务请从新游戏进入。

此独立回归入口的死亡奖励仍只发出带唯一来源的旧事件；新游戏的肉鸽入口会消费事件并实际结算。[敌人数值表](docs/ENEMY_BALANCE.md)保留原战斗参数与历史缺口；本轮奖励数量／概率由阶段4测试表补齐。六房固定测试不代替八模板随机路线验收。

## 训练场操作

A/D 加速移动，Space 跳跃；Shift 按朝向闪避150像素，0.20秒无敌，0.70秒冷却。J／世界空白左键普攻，完成一次动作后及时再次按下可衔接14／18／24三段伤害；没有自动连打或连段输入缓冲。攻击期间可闪避取消。靠近木桩攻击，青色矩形只在实际命中窗口显示；范围外挥击不扣木桩生命。

左上角“受击测试 −10”施加伤害和击退，“致死测试”进入死亡，“重新训练”真实重载整个训练场并恢复生命、位置、冷却和木桩。闪避无敌时测试伤害也会被拒绝。测试按钮是调试入口，无敌人 AI；此重开不处理资源保留或读档。移动加速、跳跃缓冲与离地容错是待手感评审的调试参数，详见 [阶段 2 计划](docs/PHASE_2_PLAN.md)。
